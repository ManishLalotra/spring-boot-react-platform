# spring-boot-react-platform

> Production Spring Boot 3.3 REST platform with Java 21, Spring Boot Actuator, React TypeScript frontend, and Docker orchestration.

## Overview
Demonstrates enterprise-grade Java web application engineering. Incorporates Spring Boot 3.3, Actuator telemetry endpoints, CORS security policies, and modern React client integration.

## Technologies
- **Backend**: Java 21, Spring Boot 3.3, Spring Actuator, Spring Web
- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite
- **DevOps**: Docker, Docker Compose, GitHub Actions CI
